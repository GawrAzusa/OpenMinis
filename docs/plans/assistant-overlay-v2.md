# 系统助理小窗 v2（实现授权）

基线：39040ef；沿用 feat/android-default-assistant，保留旧安装数据与普通聊天。

## 体验
- Android VoiceInteractionService + VoiceInteractionSession 原生系统助理窗口，不把长按电源路由到完整 MainActivity。不逆向或冒用 Gemini 资产。
- 深色墨蓝卡片、冷蓝/紫渐变边线、圆角、清晰状态、紧凑工具栏；在原应用上方显示，键盘输入、原始音频、图片预览、回复、停止/继续、展开完整聊天。
- 默认收起窗口约下半屏；展开可显示更多消息；最小化为可拖动、吸边小球。小球是明确开启的悬浮权限，未授予不能声称已出现。
- 最小化表示“暂停执行，保留会话”，不暗示执行仍在进行。暂停取消当前 Agent 调用和录音；重新打开不自动继续操作，用户点继续。既有工具若在取消前已完成，不可能撤销其副作用。
- 屏幕共享与操作手机是不同权限：共享仅让每次明确发送携带最新画面，不等于授权全程点按或实时视频理解。屏幕共享保持明显提示且可停止，锁屏停止。截图先预览，发送前可移除。

## 行为分片与所有权
1. 父：系统服务/session/可用的打字Agent桥接、原应用不跳走、小球与布局、manifest/resources/集成。
2. 音频子任务：原始WAV录制/取消、实际Agent请求传递及能力检查、普通播报去除工具命令、聚焦测试；禁止改manifest和系统小窗。
3. 屏幕子任务：独立MediaProjection consent activity/foreground service/最新帧缓存/停止与回调；禁止改manifest和模型/UI。

## 约束
- 不更换现有供应商、不导入或修改Secrets。文本模型无音频能力时明确说明，不自动ASR冒充；视觉能力同理。
- TTS使用用户配置的输出供应商，输出路径/系统回退必须可见；不播报工具名字、参数、命令、原始结果。自然程度不能用编译通过代替试听。
- 不绕过锁屏、系统权限或FLAG_SECURE。截图/原音频不自动上传；点击发送才送入既有模型。
- 任务取消、录音取消、共享停止是不同操作，均明确可见。杀进程/重建不恢复敏感授权。
- 旧客户端数据不可删除，不卸载官方包。仅授权测试Pixel8Pro/隔离模拟器，不动其他设备。
- 只生成内部候选；源码归档在既有fork Draft PR，不公开发布新APK。

## 验收
- 精确APK构建、安装文件身份；系统页面真实选择服务；从其他应用呼出不启动MainActivity，键盘可输入，小窗关闭返回原界面。
- 截图授权拒绝/成功/移除；共享开启/停止/系统撤销/锁屏；只保留最新帧；无自动云上传。
- 小球授权/拖动/吸边/恢复/停止；复用同一会话，最小化录音停止与任务暂停。
- 原音频请求真实payload、模型不支持明确错误、取消释放AudioRecord、绝不读工具命令；外部模型无账号时标明网络E2E缺口。
- 聚焦单测、设备检查和一次独立审查，修复真实阻塞；不声称Gemini全部专属服务或全双工Live已复刻。
