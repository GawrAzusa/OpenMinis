# Minis 系统小窗助理（v2）

这是基于 Android 正规数字助理接口的独立实现，不包含 Gemini 的品牌、素材或私有接口。普通启动图标仍打开原应用；系统助理入口使用 `VoiceInteractionService` / `VoiceInteractionSession`。

## 交互

- 墨蓝渐变描边小窗：文字输入、录音、截图、屏幕共享、对话展开、进入完整聊天、声音开关、新对话、停止/继续。
- 点击 `−` 收成可拖动、贴边的小球。**挂起是暂停任务，不是让 Agent 在后台继续点击手机**。录音和播报一起停止；恢复小窗不会自动恢复操作，继续任务须明确点击。
- 系统限制悬浮窗的页面可隐藏小球；锁屏停止屏幕共享和录音，不绕过系统保护。
- 文字、原声音频和所选截图只在明确发送后进入当前任务。设置/授权不是发送授权。
- 工具权限请求按当前聊天归属显示；需要 Android 系统权限时可明确展开原聊天完成授权，不自动代替用户允许。

## 从旧版升级

保留同一包名和签名下的应用数据，不需要卸载。若已把旧版 Minis 设置为默认助理，部分 Android 系统仍保留旧 Activity 入口：请在系统默认数字助理页先选“无”，再选回 Minis。应用按实际激活的语音服务判断是否设置完成，不只检查包名。

## 语音的准确边界

- 新小窗录制有大小/时长边界的 PCM WAV，原始音频直接进入兼容模型的消息，**不调用 ASR 将其偷偷替换成转写文本**。
- 实现 Gemini 原生 `inlineData` 音频及 OpenAI 兼容 Chat Completions `input_audio` 路径。模型必须按配置声明音频输入、工具调用能力；图片还需视觉能力。供应商/模型不兼容时明确拒绝，不换供应商。
- 这是按回合发送音频，**不是 Gemini Live 或双向实时音频会话**。结束录音后明确发送。
- 回复使用现有可配置的语音输出服务；未配置/不可用时界面明确显示系统声音或回退状态。没有把系统 TTS 重新命名为“自然语音”。
- 工具名、参数、命令和结果不再主动送到回复播报。小窗只选择新完成的最终助手回答；失败/部分输出不当作成功回复播报，并沿用文本清理。
- 自然音色质量、真实音频模型理解和工具执行，需要实际配置的服务与真实试听/任务验收；本地协议测试不能代替这些证据。

## 截图与共享

- 先取得通知权限，便于明确停止，再通过系统 MediaProjection 选择单应用或整个屏幕。拒绝后仍可使用文字功能。
- 一次截图自动结束投屏，留下本地待发送预览；移除/关闭/锁屏会清除。
- 连续共享只保留有界的最新帧以及用户本次选择的预览帧，不保存录像。每次点击发送时隐藏自身小窗，取更新后的画面；**不是持续把每一帧传给云端模型**。
- 停止、撤销、锁屏或不可见/受保护画面会使预览与文件失效。已明确发送并进入聊天历史的附件属于聊天记录，而不是临时共享缓存。
- 权限弹窗返回、延迟截图和共享发送都有当前操作归属检查；Home、关闭、换会话后不能用过期回调偷偷发起任务或重开小窗。

## 数据与取消

沿用原 ChatViewModel、持久化和手机工具，不创建另一个假聊天后端。保留发送中的文字/音频，直到本地数据库与聊天历史明确接收；取消发生在写入前则保留待发内容，已写入则继续原任务而非重复提交。仅本地消息事务使用短暂不可取消区间，模型网络和手机操作没有被屏蔽取消。

## 验证与分发

- 只使用聚焦的 assistant instrumentation 源集；上游全套设备测试的旧接口问题没有通过删除测试来伪造通过。
- 原生依赖的 16KB 页大小兼容问题是已有独立限制，小窗改动没有宣称修复它。
- 内部 debug APK 与上游正式签名可能不同；安装冲突时不要先卸载以免丢失数据。
- 精确源码、APK 哈希、真机/模拟器证据与未验收项由本次候选清单和验收报告记录。构建完成不等于真实模型端到端通过；源码 Draft PR 不等于公开二进制发布。
